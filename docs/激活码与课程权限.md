# 激活码与课程权限

> 状态：已实现  
> 相关代码：`apps/api/app/services/activation_codes.py`、`entitlements.py`、`apps/admin/src/app/(admin)/codes/page.tsx`

---

## 1. 权限模型

课程权限按 **科目** 授予，不按单套卷授予。

```text
用户 + 科目 -> 到期时间
```

表：

```text
user_entitlements
  user_id
  subject_id
  expires_at
  source
  last_code_id
```

一个用户在一个科目下只有一行，重复激活时更新 `expires_at`。

## 2. 免费体验

配置文件：

```text
config/entitlements/<subject_id>.json
```

当前 `psychology`：

```json
{
  "free_unit_ids": ["1"],
  "free_paper_ids": [
    "psychology-ap-2018",
    "psychology-cb-2026-mock-1"
  ]
}
```

没有有效权限时：

- Unit 1 可做；
- 2018 真题可做；
- CB Mock 1 可做；
- 其他 Unit / 真题 / 模拟题显示锁定，需要激活码。

免费内容只用于体验，不代表完整课程权限。

## 3. 激活码

### 3.1 批次

管理员一次生成一批：

```text
范围：指定科目 / 全部现有科目
有效期：1 年 / 6 个月 / 3 个月 / 1 个月 / 指定到期日
数量：1–500
备注：可选
```

生成后：

- 每个码只能使用一次；
- 码以 `AP-XXXX-XXXX-XXXX` 格式显示；
- 明文只在生成响应和 TXT 下载中出现；
- 数据库存 SHA-256 hash + 加密后的码值；
- 管理员可下载 TXT、查看明细、作废未使用码或整批未使用码。

### 3.2 作废

- 未使用的码可以作废；
- 已使用的码不能作废，避免影响已经生效的课程权限；
- 整批作废只影响未使用码。

### 3.3 时长叠加

时长码：

```text
新到期时间 = max(现在, 当前到期时间) + 码时长
```

示例：

```text
已有 3 个月
再使用 6 个月码
→ 到期时间延长 6 个月
```

### 3.4 指定到期日

指定日期码：

```text
目标时间 = 指定日期的 23:59:59（Asia/Shanghai）
```

规则：

- 当前没有权限：到期时间 = 目标日期；
- 当前到期时间早于目标日期：延长到目标日期；
- 当前到期时间已经晚于或等于目标日期：兑换失败 `CODE_ALREADY_COVERED`，不消耗激活码。

这样避免“用固定日期码反向缩短已有权限”。

### 3.5 全部科目码

生成时对当前已启用科目做快照：

```text
["psychology", "statistics"]
```

之后新增科目不会自动加入旧码。

## 4. 管理端

页面：

```text
Admin -> 激活码
```

能力：

- 生成批次并自动下载 TXT；
- 查看批次历史；
- 查看每个码的尾号、状态、使用次数；
- 下载任意批次 TXT；
- 作废单个未使用码；
- 作废整批未使用码。

接口：

```text
GET  /api/v1/admin/subjects
GET  /api/v1/admin/codes/batches
POST /api/v1/admin/codes/batches
GET  /api/v1/admin/codes/batches/{batch_id}/codes
GET  /api/v1/admin/codes/batches/{batch_id}/download
POST /api/v1/admin/codes/{code_id}/void
POST /api/v1/admin/codes/batches/{batch_id}/void
```

权限：`super_admin`。

## 5. 学生端

### 我的页面

```text
我的 -> 课程权限
```

显示：

- 已激活科目；
- 到期时间；
- 未激活/免费体验状态；
- “使用激活码”按钮。

### 锁定内容

原则：**内容列表可以进入，但不能开始。**

- 单元列表：锁定 Unit 仍可点击进入章节列表；
- 章节列表：每个锁定章节右侧显示红色锁图标，不可点击；
- 真题/模拟题列表：锁定试卷仍可点击进入试卷详情；
- 试卷详情：`Start Exam` 变为 `需要解锁`，不可点击；
- 列表页不再放“使用激活码”按钮，统一到“我的 → 课程权限”兑换。

兑换流程：

```text
输入激活码
→ 二次确认
→ 激活成功
→ 自动刷新权限
```

接口：

```text
GET  /api/v1/me/entitlements
POST /api/v1/me/activation-codes/redeem
```

## 6. 后端校验

只在界面隐藏按钮不够，以下入口必须校验：

- `GET /practice-groups/{group_id}`
- `GET /practice-groups/{group_id}/topics`
- `GET /practice-groups/{group_id}/topics/{topic_id}`
- `POST /practice-sessions`（unit/topic）
- `GET /papers/{paper_id}`
- `POST /attempts`

锁定返回：

```json
{
  "code": "SUBJECT_LOCKED",
  "message": "该科目需要激活码才能继续使用",
  "details": {
    "subject_id": "psychology",
    "kind": "paper",
    "paper_id": "psychology-ap-2025"
  }
}
```

列表接口返回 `locked` 字段，不隐藏标题和题量，方便展示课程价值。

## 7. 注意

- 激活码绑定用户账号，不绑定设备。
- 修改 `SECRET_KEY` 会导致历史码无法解密下载；生产不要随意更换，或另行做密钥轮换。
- 已使用的码不能作废；如果需要退款/撤销，需要单独的“撤销权限”功能。
- 当前没有码本身的有效期；码生成后长期有效，直到使用或作废。
- 微信/私信发码仍由人工完成，系统只负责生成、下载、兑换和权限计算。
