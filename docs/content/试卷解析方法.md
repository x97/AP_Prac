## 2. 总体流水线

```
侦察（页数/文本层/版面）
   ↓
取文（直接抽取 或 OCR）
   ↓
重建阅读顺序（分栏 / 分带 / 跨页）
   ↓
切题（题号 + 选项 + 共用材料）
   ↓
取答案（答案表 / 绿色高亮 / doc）
   ↓
取主观题与评分标准（题干 / 评分点 / 正反例）
   ↓
配图（嵌入图 或 渲染裁剪 + bbox 关联）
   ↓
入库（幂等导入 + 来源字段）
   ↓
校验（数量 / 选项完整 / 答案交叉验证 / 抽样核对）
```

每一步都先做“小样本试跑”，确认结构后再全量；全量后立即做统计校验，最后人工抽查。

## 3. 文本提取

### 3.1 有文本层的 PDF

直接用 `pypdf` 的 `extract_text()`。这类文件（2021/2022/2023/2024 FRQ/2025 FRQ/CB 题库）解析质量最高，不需要 OCR。

注意：

- **双栏页面的阅读顺序**：pypdf 多数情况下能按栏输出，但并不可靠。对双栏页面，必须用坐标重建（见 3.3）。
- **连字符换行**：行尾 `-` 表示单词被拆开（`self-` / `concept`），拼接时去掉连字符与空格。
- **连字**：`ﬁ`、`ﬂ`、`ﬀ` 等需要归一化为 `fi`、`fl`、`ff`。

### 3.2 扫描件 OCR（macOS Vision）

没有文本层的扫描件（2018、2019、2024 主卷；2025 MCQ 截图）使用 macOS 内置 Vision：

```
PDFKit 渲染/取原生图 → VNRecognizeTextRequest(.accurate, en-US)
→ 每个文本行返回 text + 归一化 bbox + confidence
```

三个关键经验：

1. **优先识别 PDF 内嵌的原生扫描图，而不是重新渲染。**
   2019 的答案是 300 dpi 原生图；按 3x 重新渲染相当于先降采样，导致答案卡整页丢行。改为直接提取 `page.images[0]` 后，答案卡 100 行全部识别。
2. **小字密排页面要按栏切 ROI。**
   整页识别会在栏边界丢字（例如 “activities” 变成 “tivities”）。把页面按左/右半页分别识别，再拼回坐标，可显著改善。
3. **混合版式要重叠切分。**
   例如 2018 第 3 页是“通栏图 + 通栏题干 + 下方双栏”。用 0–50%/50–100% 切分会把通栏题干截断；用 0–75% 与 25–100% 两个重叠区域识别，再按 (文本, y) 去重，才能既保留通栏长句又不丢栏内文字。

Vision 的局限：

- 单页密排小字（如答案卡三栏）容易丢行，需要提高原生分辨率或按栏切分。
- 个别字符会误读：`(B)` → `3)`、`(C)` → `)`、`1` 单独成行时容易漏。
- 置信度低的行不能直接丢，先保留，后续按结构校验处理。

### 3.3 阅读顺序重建（关键）

把 OCR/文本片段还原成“人读书的顺序”，需要按版面分三种情况：

| 版面 | 判定 | 处理 |
|---|---|---|
| 单栏通页 | 文本行横跨页面中线 | 全部行按 y 降序 |
| 双栏 | 左右两侧各有 ≥3 行且没有跨栏行 | 左栏全部 → 右栏全部 |
| 混合（上双栏 + 通栏图/题 + 下双栏） | 页面存在大段纵向空白 | 按纵向空隙切成横向“带”，每带单独判定栏数 |

实现要点：

- 以 4pt 为容差按基线把片段聚成行，行内按 x 排序。
- 同一基线被 OCR 拆成多个框时（如 `(B)` 和 `1`），先按 y 聚簇、再按 x 拼接，间隔小于 0.05 视为连续。
- 带与带之间用“无文字的大纵向间隔”切分；没有题号/选项的带视为图注或坐标轴，直接丢弃。

## 4. 题目切分

### 4.1 题号识别

```python
QSTART = re.compile(r'^(\d{1,3})\.(\s|$)')   # 允许 "4." 独占一行
OPTION = re.compile(r'^\(?([A-E])\)\s*(.*)$') # 容错缺左括号：D) Projective
```

两个关键点：

1. **允许题号独占一行**。2024、CB 题库里很多题号单独成行，随后才是题干；只匹配 `数字. 空格` 会漏题。
2. **题号必须递增校验**。题干里会出现 `85.`（“平均分 85. However…”）这种伪题号。只接受“当前题号 +1 ~ +3”的编号，否则视为正文。2021 Q266 就是因为这一个字符被错挂到第 85 题。

### 4.2 选项切分

- 选项行以 `(A)`–`(E)` 开头，续行并入当前选项。
- 官方 2024 起为 4 选项（A–D），2018–2023 为 5 选项（A–E）。
- 选项字母可能被 OCR 粘进文本（`A longitudinal design`、`© A case study`），需要按字母所在的 x 坐标判断是否剥离，不能一律删首字母——否则会把冠词 “A” 误删。

### 4.3 共用材料（lead-in）

`Questions 62-64 are based on the following.` 这类引导句不属于上一题，而是下面几题的共用材料。

处理：遇到 lead-in 时结束当前题，把后续非题号文本收进 context 缓冲；接下来的题目按题号范围继承该 context，存入 `questions.context`。这样 Q61 的选项不会被表格数字污染。

### 4.4 噪声过滤

会污染题目/选项的典型噪声：

| 噪声 | 例子 | 处理 |
|---|---|---|
| 页眉页脚 | `Scoring Guide`、`- PAGE : 12 -`、`GO ON TO THE NEXT PAGE.` | 正则整行丢弃 |
| 坐标轴/图例 | `9%`、`Low`、`High`、`Few`、`Pessimism` | 规则匹配 + 字母数字占比过滤 |
| 表格单元格 | 数据表里的数字行 | 按 y 区间 + 内容模式过滤 |
| 下一题的 lead-in | `The following question(s) refer to…` | 作为 context，不并入选项 |
| UI 元素 | `Mark for Review`、进度条、AP logo | 2025 截图专用过滤 |

## 5. 答案提取

不同来源的答案形式不同，按“最可靠优先”的顺序处理：

### 5.1 文字答案表

2021 第 24 页是 `1 D 26 B 51 A 76 E` 的三栏表；解析为 `(题号, 字母)` 对。

### 5.2 绿色高亮（2022 / 2023 / 2024 / CB 题库）

这些 PDF 用浅绿色矩形标出正确选项。用 `pdfplumber` 读取矢量矩形：

```python
# 填充色 (0.902, 1.0, 0.902)，边框 (0.228, 0.568, 0.247)
if g > r + 0.02 and g > b + 0.02 and r > 0.5:  # 浅绿填充
```

把矩形 bbox 与选项行的垂直中心对齐，即得到答案。

注意：

- `non_stroking_color` 可能是单个 float（灰度），必须先判断类型。
- 页面可能同时存在“文字答案”和“绿色标记”，两者交叉验证（见第 9 节）。
- 一个页面可能在顶部延续上一题的选项，题号状态必须跨页保持。
- 题号递增校验同样适用于答案提取。

### 5.3 `.doc` 答案表（2025 MCQ）

`心理学MCQ答案.doc` 是 15 行 × 5 个字母的纯文本。用 `textutil -convert txt` 转文本后，用正则提取 A–D 字母并映射到 1–75 题。

### 5.4 答案缺失时的处理

> Barron's 2027 Practice Tests 1–3 的答案来自本书的 `Answer Explanations`，入库时 `answer_source='book_answer'`、`answer_confidence='high'`；不是 College Board 官方答案。

- 原始文件确实没有答案：`correct_answer` 留空，界面进入“浏览模式”，不判分。
- Myers 题目已于 2026-10-28 删除（含当时用 `ai_inferred` 补的 814 条答案），当前数据库没有 AI 推断答案。
- CB 题库已有绿色标记，不使用 AI 推断答案；此前为 CB 生成的 AI 答案已撤回。

```sql
SELECT answer_source, COUNT(*) FROM questions GROUP BY answer_source;
-- book_answer       387（Barron 答案解析）
-- official          750（真题答案表）
-- official_highlight 1717（绿色标记）
-- NULL/none          22（FRQ / 无答案）
```

## 6. 主观题（FRQ）

### 6.1 题干

- 从题目 PDF 按题号起始页抽取，遇到 `Part A/B/C`、`•` 项目符号另起段落，其余行合并。
- 保留完整研究摘要与 Source 材料（2025 AAQ/EBQ 题干可达 6k–12k 字符）。
- 去掉页眉页脚与 `STOP / END OF EXAM` 残留。

### 6.2 套卷合并

2024、2025 的 FRQ 分 Set 1 / Set 2（两套不同卷型）。合并为同一份 paper，用 `questions.form` 区分：

- Set 1 题号 1–2
- Set 2 题号 3–4（受 `UNIQUE(paper_id, section, number)` 约束）
- 前端展示时按套内编号还原（Q1/Q2 + Set 标签）

### 6.3 评分标准

遇到过三种官方格式：

| 格式 | 例子 | 解析方式 |
|---|---|---|
| 2025 `parts_2025` | `Part A … (0–1 points)` + 0/1/2 标准 | 按 Part 标题切分，`criteria` 存多级标准 |
| 2018–2023 `legacy_points` | `Point 1: …` / `1: …` + “Response must…” | 按 Point/编号标题切分，每点 1 分 |
| 2024 Part A/B | Part A 下有多个小问，每问 1 分 | 按 “1 point” 标记分组，一个评分点可有多个可选标准 |

统一存入：

- `frq_rubrics`：总分、General Considerations、格式
- `rubric_parts`：`label`、`title`、`max_points`、`criteria`(JSON)、`decision_rules`、`examples_positive`/`negative`(JSON)、`notes`、`sort_order`

提取原则：**优先取 “0 1” 分值标记之后的文字**作为该点评分标准；直接取 “The response must…” 会把总则里的通用句子误当标准（这个坑出现过一次）。

### 6.4 已知数据缺口

2018 FRQ 2 的官方评分标准在源 PDF 里只到 Point 3（后续页缺失），因此该题只有 3 个评分点。这是源文件缺失，不是解析遗漏，已在文档与数据库中标注。

## 7. 图片处理

### 7.1 两种取图方式

| 方式 | 适用 | 优点 | 缺点 |
|---|---|---|---|
| 直接提取嵌入图 | 图片是独立对象（多数真题、2025 截图） | 原始分辨率、无损 | 拿不到图片位置 |
| 渲染后裁剪 | 扫描件整页是一张图；需要精确区域 | 可按 bbox 精确裁 | 受渲染倍率影响 |

实践中：

- 单图页 → 直接提取 `page.images[0]`。
- 多图页 / 需要 bbox → `pdfplumber` 取图片 bbox，再按 3x 渲染裁剪。
- 扫描件（2018/2019/2024）整页是一张图，图与正文在同一张扫描里，只能按视觉区域裁剪。

### 7.2 图题关联

这是最容易出错的部分。不同来源的排版规则不同：

| 来源 | 图的位置 | 关联规则 |
|---|---|---|
| 2018/2019/2021/2022/2023 真题 | 图通常在题号与题干之间，或题干下方 | 先按题干关键词（graph/table/figure/shown）判断，再用“图上方最近的题号”兜底 |
| 2024 真题 | 同上（题号 → 图 → 题干） | 图上方最近的题号 |
| 2025 MCQ 截图 | 左屏刺激材料、右屏题目 | 按左右半屏切分，左半为图/材料 |
| CB 题库 | 图在题号之后、题干之前 | 图上方最近的题号（不是下一题） |

实际踩过的坑：

- 2019 Q96/Q97：图在 Q96 之后、Q97 之前，但题干明确写 “scatterplot above”，图属于 Q97。仅按“上一题”会挂错。
- 2021 Q23：五个散点图分别是选项 A–E，不是一张整图。必须按选项级素材存储。
- 2021 Q24/Q25：同一张分布图，Q25 题干写 “above graphs”，两题共享。
- 2024 Q24/Q26/Q33/Q41/Q54：图在题干上方，裁剪时容易带上题干文字。
- CB 题库：图在题目编号之后、题干之前，按“上一个题号”才是正确归属。

### 7.3 bbox 与裁剪

- `pdfplumber` 的坐标单位是 PDF points，页面常见 612×792 或 595×842。
- 渲染时 `pixel = point × scale`；先渲染整页再裁，避免坐标二次换算错误。
- 裁完用“反色 + 阈值 + getbbox”自动去掉白边；再用中值滤波去掉扫描噪点。
- 如果图片包含坐标轴标签，bbox 要向外扩 8–15pt，否则会切掉 “Mean Score…” 之类的轴标题。

### 7.4 存储

`assets` 表：

| 字段 | 说明 |
|---|---|
| question_id | 所属题目 |
| option_label | NULL = 题目级；`A`–`E` = 选项级 |
| kind | `figure`（紧贴图）/ `table`（表格）/ `option`（选项图）/ `page`（整页兜底） |
| path | 相对项目根目录，如 `assets/psychology/images/2025/fig_q016.png` |
| page | 来源 PDF 页码 |
| bbox | 裁剪框（比例坐标），便于追溯 |

## 8. 入库

### 8.1 核心表

- `papers`：试卷元信息（年份、类型、来源、中文标题、`source_id`）；`paper_type` 只保留 `real_exam` / `mock_exam` / `unit_practice`，教材课后题与章末练习统一归入 `unit_practice`
- `questions`：题干、context、页码、答案、解析、`form`、`answer_source`
- `options`：A–E 选项、`is_correct`、`explanation`（原书/官方正确选项解析）与 `ai_explanation`（AI 根据题干和答案生成，单独字段、单独标注）
- `ap_knowledge.db` 的 `question_analysis` / `question_kp_links` / `question_keywords` / `question_concept_links`：题目解析关联（覆盖全部有答案 MCQ）；`question_concept_links` 是概念层目标，`question_kp_links` 保留 legacy/UI 兼容；`question_id` 是逻辑引用，不建跨库外键；流程见 `../prompts/03_question_concept_linking.md`（旧 KP 版见 `../prompts/legacy/01_question_kp_linking.md`）
- `assets`：图片（题目级/选项级）
- `frq_rubrics` / `rubric_parts`：主观题评分标准

### 8.2 幂等导入

每个导入脚本在写入前按 `paper_id` 删除旧数据（options → assets → rubrics → questions → paper），再重建。这样重复运行不会产生重复行，也方便修正解析规则后重跑。

注意删除顺序要符合外键依赖；SQLite 默认不强制外键，但仍建议按依赖倒序删除。

### 8.3 来源与版本

- `content_sources`：`source_id`、`kind`、`edition`、`target_year`、文件路径
- `papers.source_id` / `textbooks.source_id`

例如 CB 题库记录为 `edition=2026, target_year=2027`。以后更新题库只需新建 source 记录并重跑导入。

## 9. 质量校验

每次全量导入后执行以下检查：

1. **数量**：题号是否连续（1..N），总数是否与源文件标题一致（如 “100 Questions”）。
2. **选项完整性**：每道 MCQ 是否恰好 4 或 5 个选项；缺项单独列出。
3. **答案覆盖**：有答案的题数、无答案的题数；答案分布是否合理（A–E 不应严重偏斜）。
4. **交叉验证**：同一题同时有“文字答案”和“绿色标记”时逐题比对。
   - CB 题库：900 题有文字答案，1717 题有绿色标记；重叠的 900 题中 899 题一致。唯一冲突 Q247（文字写 D、绿色标 B），题干描述的是“先学食物词再记新食物词”，属前摄干扰，取绿色答案 B。
   - 2022/2023 真题：源文件没有文字答案表，答案全部来自绿色标记；通过答案分布与抽样核对确认。
5. **抽样人工核对**：每套卷抽 5–10 题，对照渲染页确认题干、选项、答案、页码。
6. **图片核对**：把图片拼成 contact sheet 目视检查；检查关联题号是否与题干描述一致（如 “the graph above”）。
7. **知识点**：当前 `ap_knowledge.db` 有 2 本书、399 个 section、1,538 个 KP（Barron 860 + Myers 678）、1,781 条别名；1,105 条规范概念（402 core + 703 supporting）；全部 1,538 个 KP 已映射到概念；所有 KP 的 `subject_id='psychology'`，书内 `(subject_id, normalized)` 无重复。

## 11. 经验总结

1. **先判断文本层，再决定方案**：有文本层的 PDF 不要 OCR，OCR 只用于扫描件/截图。
2. **结构永远比内容重要**：先确定栏数、题号序列、选项边界，再谈文字准确率。
3. **题号必须做序列校验**：题干里出现数字加句点是常态，不能见数字就切题。
4. **答案要多源交叉**：文字答案 + 绿色标记 + 人工抽查，三者不一致时以内容合理性裁决。
5. **图片关联要按来源分别写规则**：真题、截图、题库的图文位置规律不同，不能一套逻辑套到底。
6. **裁剪后一定要目视检查**：自动 bbox 很容易带上题干或切掉坐标轴标签。
7. **保留来源字段**：`source_id`、`page`、`bbox`、`answer_source` 让后续修正和审计成为可能。
8. **已知缺失要显式记录**：例如 2018 FRQ2 的评分标准缺页，不能假装完整。
