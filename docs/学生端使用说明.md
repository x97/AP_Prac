# 学生端使用说明

## 登录

网页端使用 **邮箱 + 密码** 登录，也可以用邮箱验证码注册、通过邮箱找回密码。

微信小程序支持：

- 微信一键登录（首次登录会创建一个未绑定邮箱的账号）
- 邮箱 + 密码登录
- 邮箱 + 验证码注册
- 通过邮箱找回密码
- 在 **我的 → 绑定邮箱** 绑定邮箱，绑定后微信和邮箱都能登录同一个账号

在微信端用邮箱登录或注册成功后，会自动把当前微信关联到该邮箱账号，下次直接点“微信一键登录”即可进入同一个账号。如果该微信此前已经有一个虚拟账号，虚拟账号的做题、背单词记录会自动合并到邮箱账号。

如果绑定的邮箱已经是老账号，微信端的学习记录也会合并到该邮箱账号。

## 首页

可以看到考试倒计时、继续上次练习、最近记录、记忆卡片和老师咨询入口。

## 单元练习

进入 **单元练习** → 选择 Unit → 选择章节。

- 做完立即显示答案和解析
- 右侧显示相关知识点
- 可以收藏题目、写笔记
- 答错的题自动进入错题本

## 知识图谱
知识图谱右上角有「全屏 / 退出全屏」按钮，全屏时也可以按 Esc 退出；全屏只放大图谱，不改变内容。

进入 **知识图谱**（手机底部为「图谱」）后：

- 先看到 Unit 结构：每个 Topic 显示 3 个核心概念和跨 Topic 桥
- 点击 Topic：打开横向知识树；标题在最左，章节和知识点向右展开；知识点只显示英文
- 一级章节用分色卡片，二级/三级知识点用浅色卡片；长标签自动换行，不会裁字
- 连线从父节点中心连到子节点中心；多个子节点使用垂直分叉线
- 单元/章节标题只显示英文
- 图谱区域可以上下滚动；滚动滚轮查看，`Ctrl / Cmd + 滚轮` 缩放，也可以拖动；左上角返回 Unit 结构，右上角为缩放按钮
- 有子节点的卡片左侧有 `+ / −`：点 `+ / −` 展开/收起；点卡片本身是查看该知识点的释义
- 右上角 `Collapse / Expand` 可以一次收起或展开全部
- 点击有颜色的概念节点：右侧显示定义、教材关系、真题易混和关联题目；灰色/纯文本结构标签不可点击
- 点击「真题易混」或「Related Questions」中的题目：打开只读预览，只能看题，不能作答
- 图谱只显示账号已解锁的 Unit；未解锁 Unit 只显示锁定状态

## 真题 / 模拟题

进入 **真题**，可以看到免费试卷、历年真题和模拟题。

选择模式：

- MCQ Only：只做选择题
- FRQ Only：只做主观题
- MCQ + FRQ：整套考试

考试中可以暂停、标记题目、看答题卡，但不会边做边批改，也不会提前写入错题本。点击浏览器返回按钮会先显示「正在暂停考试…」至少 1.5 秒，暂停成功后自动返回上一页；暂停失败会留在考试页并提示重试。刷新或关闭标签页也会尽力冻结计时。交卷时会显示「正在批改中…」，批改完成后才统一更新成绩和错题本；交卷后才能看解析。FRQ 需要自己按评分标准打分。

## 复习工具

- **错题本**：自动记录错题，可以标记已掌握/未掌握，也可以开始错题练习卷。
- **收藏**：练习中点题目右上角 **Bookmark** 收藏。
- **笔记**：做题时写笔记，全部汇总在笔记本。
- **记忆卡片**：点击卡片翻面；`Already Know` 表示认识，`Review Later` 表示还不熟。卡片按到期顺序连续出现，不再按组抽取；每天最多引入 60 张新卡。新卡第一次 `Already Know` 后 30 分钟内会再次出现，第二次后进入 1 / 2 / 4 / 7 / 15 天间隔。也可以自己创建卡片。

## 我的

在 **我的** 页面可以修改昵称、查看课程权限、输入激活码、查看收藏/笔记/错题本，以及退出登录。

- **已激活科目**：首页和「我的」页会列出当前账号已激活的科目、有效期和激活数量；未激活科目仍可体验免费内容。
- **主题颜色**：可选择经典蓝、海盐蓝、青碧、森林绿、薄荷绿、琥珀金、日落橙、赤红、樱花粉、紫罗兰、靛蓝、石墨灰。
- 主题保存在当前浏览器；切换账号或换设备不会自动同步。
- 登录后的应用页面跟随所选主题；公开落地页固定使用经典蓝，不跟随个人主题色。

## 免费和激活码

免费可以体验：

- 1 个单元练习
- 1 套真题
- 1 套模拟题

其他内容会显示锁定。

解锁方式：

**我的 → 课程权限 → 使用激活码 → 确认激活**

激活后显示有效期；新时长会叠加到已有有效期上。

## 其他

- 题目有问题：点击题目右上角 **Report**。
- 课程咨询 / 激活码问题：点击 **微信咨询/获取激活码**。
- 广告卡当天关闭后，第二天会重新显示。
