解析过程中解决的几个问题

这份 PDF 是 62 页纯扫描件（无文本层），所以走的是 macOS Vision OCR：

1. 原生图识别：先按 PDF 内嵌的 300 dpi 原图识别，而不是重新渲染，Question Descriptors 那类小字才识别得出来。
2. 双栏阅读顺序：早期按整页识别会把左右两栏交错，导致题目顺序变成 1,4,5,2,3。改为按纵向空隙切横带、带内再分栏。
3. 混合版式：第 17 页是“上双栏 + 中间通栏图 + 下通栏题”，按栏识别会把 Q31 切碎；横带方案解决了。
4. 图注污染：坐标轴文字（9%、Annual income…）会被拼进选项 E，已按图注模式过滤。
5. 共用题干：第 23 页的表格数据原本被拼进 Q61 的选项 E，现改为挂到 Q62–64 的 context。
6. 答案错误：Q62 的选项 B 一度识别成 117，ROI 分栏识别后修正为 11。
